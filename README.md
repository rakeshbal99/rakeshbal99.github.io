# Rakesh Bal — Personal Website

Personal portfolio and blog of Rakesh Bal, an MLOps Engineer. Built with Jekyll, hosted on
GitHub Pages at **[rakeshbal99.github.io](https://rakeshbal99.github.io/)**.

## Pages

| Page | What's there |
|------|--------------|
| [About](https://rakeshbal99.github.io/about) | Bio |
| [Blog](https://rakeshbal99.github.io/archive) | Posts on ML engineering and personal experiences |
| [Poems](https://rakeshbal99.github.io/poems) | A poetry collection |
| [Photos](https://rakeshbal99.github.io/photos) | Photography, grouped by trip |
| [CV](https://rakeshbal99.github.io/cv) | Resume/CV |
| [Research](https://rakeshbal99.github.io/research) | Published papers and research projects |

## Built with

Jekyll 3.10+ · Markdown + Liquid templates · CSS3 with custom properties for light/dark
theming · vanilla JS (theme switcher only) · Atom feed via `jekyll-feed` · hosted on GitHub
Pages.

## Running locally

```bash
bundle install            # install dependencies (one-time)
bundle exec jekyll serve  # serve at localhost:4000 with live reload
```
